Add a Patent
How to add entries ▼

Open this file in a text editor and scroll to the PATENT DATA block near the bottom. Paste a new object into SANTA_CRUZ or SAN_JOSE. Order doesn't matter — the page sorts by year and draws the decade rules for you.

{
  year: 1919,                       // omit for an undated patent
  title: "Doll's Eyes",
  women: ["Mabel P. Smith"],       // shown in gold
  others: ["Putnam D. Smith"],    // optional co-inventors
  number: "US1234567A",           // optional
  url: "https://patents.google.com/patent/US1234567A",
  design: true,                   // optional, tags it as a design patent
  note: "Patent number still to confirm"  // optional
}

Leave url off and the card shows a teal Search Google Patents button built from the inventor's name instead — useful while you're still hunting the number down.
